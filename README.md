# Portfolio Website

This repository contains the source code for my personal portfolio website. The site showcases my skills, projects, and experiences as a Computer Science and Data Science student, providing a central place for networking and professional growth.

## Website Features

- **About Me**: A brief introduction and professional summary.
- **Projects**: Highlights of key projects, including descriptions, technologies used, and links to GitHub repositories or live demos.
- **Skills**: A showcase of technical and soft skills relevant to my field.
- **Contact Section**: Includes a form and links to my social profiles (e.g., LinkedIn, GitHub, etc.).
